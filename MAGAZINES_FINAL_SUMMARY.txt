## 🚀 How to Use

### Access the Pages
Navigate to these URLs in your browser:

```
Magazines:
  /admin/magazines         → List magazines
  /admin/magazines/create  → Create magazine
  /admin/magazines/:id     → Edit magazine

Templates:
  /admin/templates         → List templates
  /admin/templates/create  → Create template
  /admin/templates/:id     → Edit template
```

### Or Use Navigation
- Click "Magazines" in the navbar → manage magazines
- Click "Templates" in the navbar → manage templates

### Basic Workflow
1. Create templates (HTML/CSS/fields)
2. Create magazines (select & configure templates)
3. Users create magazine instances
4. Users fill in content for each page

## 🔌 API Integration

Uses your existing backend endpoints:

```

```

Query parameters:
- `page` — Pagination
- `limit` — Items per page
- `q` — Search query
- `isActive` — Filter by status
- `sort` — Sort order

All connected via your `api` client from `lib/api`.

## 💡 Key Concepts

### Templates
- Define page structure (HTML/CSS)
- Add dynamic fields
- Can be reused in multiple magazines
- Versioning: create new versions for structural changes

### Magazines
- Collections of templates
- Set page constraints
- Configure template usage rules
- Users create instances from magazines

### Instances
- User magazines created from magazine templates
- Each has pages from assigned templates
- Users fill in content
- Can be published
